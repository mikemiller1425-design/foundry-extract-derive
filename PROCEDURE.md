# Procedure — extract then derive

1. Name the planet path and the law file.
2. List stages that already have folders.
3. Pick the first milestone whose “done when” is observable.
4. KEEP / REPAIR / OUT.
5. Derive one SPEC (outcome, allowlist, must-not, accept, handoff).
6. Copy that SPEC to Foundry `SPEC.md`. Run `./foundry-advance spec`.
7. Derive the next SPEC only after that ticket is accepted.
